# Aura

An open-source macOS 26 Tahoe customization utility

## Features
- Toggle system animations on/off
- Apply Liquid Glass tinting presets
- Customize Dock behavior
- Automatic backup before every change
- Export/import presets as JSON
- One-click reset to macOS defaults

## Requirements
- macOS 26 Tahoe or later
- Xcode 16+
